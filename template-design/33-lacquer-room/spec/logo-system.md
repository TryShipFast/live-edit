# 33 Lacquer Room — logo system
- **Mark:** an almond nail shape (rounded rect 16×26, r 8) with a lacquer drop knocked out. Reads at 16px as a tall rounded bar.
- **Files:** assets/33/logo-mark.svg (oxide green), logo-mono.svg (ink), logo-lockup-light.svg (on paper/white), logo-lockup-dark.svg (on ink), favicon.svg.
- **Wordmark:** "Lacquer Room" in Gloock 22px, sentence case. In the site the lockup is inline SVG (keeps the web font).
- **Clear space:** the width of the mark on all sides. **Min size:** mark 14px tall, lockup 120px wide.
- **Don'ts:** no gradients, no pink fill, don't stretch the almond, don't put the mark on photos without the ink panel.
